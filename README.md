# Python Quest

A hands-on introduction to Python coding for children aged about 8–12. There are two levels, and each one takes about 10 minutes.

**Play it here:** https://morganjsm.github.io/python-quest/

Pip the snake guides you through short missions. In each one you write and run real Python code in the browser, and you earn a star when you complete it. Finish a level to get a certificate with your name on it, which you can save as a picture or print.

## Level 1: First steps

1. **Say hello** – make the computer talk with `print()`
2. **Boxes** – store things in variables
3. **Maths** – use Python as a super calculator
4. **Questions** – ask the player something with `input()`
5. **Choices** – build a number-guessing game with `if` and `else`
6. **Drawing** – use a `for` loop to draw shapes with a turtle

## Level 2: Game maker

Level 2 opens once Level 1 is finished. There is also an "Unlock it anyway" button for children who already know the basics.

1. **Lists** – keep lots of things in one list and add to it with `.append()`
2. **Random** – roll a dice and build a superpower picker with `random`
3. **Too high?** – a guessing game with a `while` loop and `elif`, plus a bug to fix
4. **Art** – mix lists, loops and random colours to draw a turtle spiral

Every mission has a hint button. If something goes wrong, the error is explained in plain words.

## How to use it

- **Online:** open the link above in any modern web browser on a computer, tablet or phone.
- **Offline:** on this GitHub page, click the green **Code** button and choose **Download ZIP**. Unzip it, then open `index.html` in a browser. Keep the `engine` folder next to `index.html`, because that's where Python lives.

Progress (stars, code and the name on the certificate) is saved in the browser on that device. Nothing is sent anywhere.

## What's in this repository

- `index.html` – the whole lesson: missions, design and certificate
- `engine/` – Skulpt, the tool that runs Python inside the browser
