# Python Quest

A 10-minute, hands-on introduction to Python coding for children aged about 8–12.

**Play it here:** https://YOUR-USERNAME.github.io/python-quest/

Pip the snake guides you through six short missions. In each one you write and run real Python code in the browser, and you earn a star when you complete it.

## The missions

1. **Say hello** – make the computer talk with `print()`
2. **Boxes** – store things in variables
3. **Maths** – use Python as a super calculator
4. **Questions** – ask the player something with `input()`
5. **Choices** – build a number-guessing game with `if` and `else`
6. **Drawing** – use a `for` loop to draw shapes with a turtle

Every mission has a hint button. If something goes wrong, the error is explained in plain words.

## How to use it

- **Online:** open the link above in any modern web browser on a computer, tablet or phone.
- **Offline:** download `index.html` and open it in a browser. It works without an internet connection.

Progress (stars and code) is saved in the browser on that device. Nothing is sent anywhere.
